Unit 1: Amplitude modulation

Standard AM: s(t) = Ac[1 + μcos(2πfmt)]cos(2πfct); μ = Am/Ac. Bandwidth = 2fm. Pt = Pc(1 + μ²/2). Efficiency η = μ²/(2+μ²), max 33.3% at μ=1. μ>1 = overmodulation: the envelope detector distorts. Two thirds of the power is wasted in the carrier; DSB-SC removes it, SSB also halves the bandwidth. Superhet: fIF = fRF - fLO constant; image frequency = fRF + 2fIF.

Unit 2: FM and PM

β = Δf/fm. Carson: BW ≈ 2(Δf + fm) = 2fm(β+1). NBFM: β < 1 (BW ≈ 2fm); WBFM: β > 1. FM: Δf ∝ message AMPLITUDE (independent of fm). PM: phase deviation ∝ message amplitude, so Δf ∝ Am·fm. Broadcast FM: Δf = 75 kHz, fm = 15 kHz, β = 5, BW = 180 kHz (200 kHz channel). FM is constant-envelope: noise is clipped by a limiter, so it beats AM against noise but needs more bandwidth.

Unit 3: Sampling, PCM, quantisation

Nyquist: fs ≥ 2fmax. Below it, aliasing: the tone appears at |f - k·fs| (nearest k). Levels L = 2n; step Δ = 2A/L; max quantisation error Δ/2; SNRq = 6.02n + 1.76 dB (full-scale sine; each extra bit = +6 dB). PCM bit rate = n·fs; minimum channel BW = n·fs/2. Delta modulation: 1 bit/sample, suffers slope overload (step too small) and granular noise (step too big). DPCM codes the difference between samples.

Unit 4: Digital modulation (ASK / FSK / PSK)

Bit error probability (coherent): BPSK Pb = Q(√(2Eb/N0)); coherent BFSK Pb = Q(√(Eb/N0)); so PSK is 3 dB better than FSK for the same BER. Bandwidth: ASK and PSK about 2Rb; FSK about 2Δf + 2Rb (widest). PSK has constant envelope and best noise performance but needs a coherent carrier; ASK is simplest but most noise-sensitive. Multiplexing and spread spectrum: TDM shares time, FDM shares frequency, CDMA shares codes.

Unit 3: Matched filter and ISI (eye diagram)

Matched filter: h(t) = s(T - t); maximises output SNR at t = T; SNRmax = 2E/N0 (depends on energy, not pulse shape). Nyquist criterion for zero ISI: pulse = 0 at all other sampling instants. Raised cosine: BW = (1+α)Rs/2; α=0 is the ideal sinc (minimum BW Rs/2 but timing-sensitive), α=1 doubles the BW. Eye opening shrinks with noise and ISI; timing error closes the eye horizontally.

Unit 4: Multiplexing, spread spectrum, switching, OSI

TDM bit rate = N·n·fs (+ framing). FDM bandwidth = N·BW + (N-1) guards. Processing gain Gp = Tb/Tc = Rc/Rb (dB: 10log10). Jamming margin = Gp - (Eb/N0)min - losses. FH-SS: carrier hops over many channels by a pseudo-random code (fast hop: several hops per symbol; slow hop: several symbols per hop); DS-SS multiplies by a fast code.

Unit 5: Information theory

Information of a symbol I = log2(1/p) bits. Entropy H = Σ p log2(1/p) ≤ log2M (equal only for equiprobable symbols). Source coding: average length L ≥ H; efficiency = H/L; Huffman gives the shortest prefix code (merge the two least probable symbols repeatedly). Shannon capacity C = B log2(1 + S/N) with S/N as a ratio, not dB! BSC capacity C = 1 - H(p). Reliable communication is possible at any rate below C (noisy-channel coding theorem).
