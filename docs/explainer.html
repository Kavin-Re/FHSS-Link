Spread spectrum, step by step

A message bit is multiplied by a fast random-looking code (the chips), sent, hit by a jammer, then multiplied by the same code again. The jammer is smeared out; the message adds up. Move the sliders.

1. Bits

2. Spread: bits x code (what is transmitted)

3. Received: spread signal + jammer tone + noise

4. Despread: received x code, then add up over each bit

Same idea with hopping

Instead of multiplying by a fast code, the transmitter jumps between channels in a secret order. A jammer on one channel only hits the slots where we happen to be on it: with M channels that is 1 slot in M. Hopping spreads the signal in time; spreading by a code spreads it in bandwidth. Both give the receiver an advantage over a jammer who does not know the code.
